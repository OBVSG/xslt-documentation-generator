template: docReturn

Generate doc for return value of an xsl:function. If possible, use the return type declared in @as. If the return type of the documentation doesn't match @as of the function, throw an error message and terminate. If the return type is documented, but not declared in the function declaration, throw a warning. In this case, the return type from the documentation is used.
